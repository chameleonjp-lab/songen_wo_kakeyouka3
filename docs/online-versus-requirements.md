## 目的と範囲

離れた場所にいる二人が、同じ『尊厳を賭けようか』のルールで、スマートフォンのブラウザから一試合を遊べるようにする。作品名は『尊厳を賭けようか3』。シリーズの無印を対戦ルールと操作の原本にする。既存の3を収容するリポジトリと公開先を使い、公開する中身をオンライン専用版に入れ替える。

- 無印の原本は [固定コミット 060b251](https://github.com/chameleonjp-lab/songen_wo_kakeyouka/blob/060b251a7016725bfd4e7886936eabf223b092d0/index.html)。同じルールかどうかは、この版のコードと試合の再生結果で判断する。
- 入れ替え対象は [3D版の固定コミット ef0e1d4](https://github.com/chameleonjp-lab/songen_wo_kakeyouka3/tree/ef0e1d4e47dff003475edcf88a16bb4d52db29b9)。アプリ、素材、依存関係、試験、説明、配信設定を新作の構成に揃える。
- 初回公開は招待制のフレンド対戦。公開マッチング、観戦、チャット、レート、対戦履歴の公開は後続候補。実験場の『尊厳を賭けようか3』専用ランキングに、ベストスコア・戦績・ソンカケptの三つを載せる。無印や旧3D版はそれぞれの作品の記録として扱う。

## 要件

### R1　6画面の構成と遷移

| 画面 | 表示と操作の順番 |
| --- | --- |
| ① ホーム | 翻訳言語選択（左上）→ タイトル →「ゲームの準備」→「ルール説明」→「Xにシェア」→「ランキング」。ゲームの準備を押すと②。ルール説明はホーム上で開閉する |
| ② プレイヤー登録 | この端末のプレイヤー1名分の名前入力（任意）→ 顔選択 →「ルームを立てる」→ 参加する人のルームID入力欄と「参加する」。ID発行後はID本体と「IDをコピー」「Xにシェア」「待機室へ」を表示する。招待リンクは②を開いてIDを入力済みにする |
| ③ 待機室 | 結果発表と同じ左右配置に、互いの顔と名前を表示する。ルームが割り当てた側に「あなた」を表示する。相手が来る前は「相手を待っています」を表示し、二人が準備完了すると3秒のカウントダウン後に④へ進む |
| ④ ゲーム画面 | 無印の絵文字対戦。③の左右を使い、試合中は顔、残り時間、部位の状態、操作ボタンを表示する |
| ⑤ 結果発表 | サーバーが確定した最後の盤面を固定し、勝敗と決着理由を表示する。両者の顔・部位の破壊状態を隠さず、プレイヤーが端末のスクリーンショットを撮れるようにする。盤面の外の「スコア結果へ」を押したときに⑥へ進む |
| ⑥ スコア結果 | 自分の勝敗、今回のスコア、計算の内訳を表示する。ランキング反映を待っている場合も結果から各ボタンへ進める。ボタン順は「ルームに戻る」（ホストのみ）→「Xにシェア」→「ホーム」→「ランキング」。ゲストは「Xにシェア」から始まる |

- 12文字のルームIDは試合の参加先を示す。コピーできない端末でも、②のIDを選択・コピーでき、自分で入力して参加できる。②のX共有はIDと招待リンクを投稿欄に入れる。①は作品の紹介、⑥は自分の結果を添えた作品紹介とし、公開URLを使う。投稿は操作した人が確定する。
- 最初の実装では、待機室に入った時点でホストを左、ゲストを右に割り当てる。双方で同じ左右を使い、自分の側を示す「あなた」だけを付け替える。名前が空欄なら左・右に応じて、その言語の「プレイヤー1」「プレイヤー2」を表示する。
- ⑥でホストが「ルームに戻る」を押すと、サーバーが同じIDの待機室を開き直し、③に戻す。ゲストは⑥の表示を続けられる。同じ相手ともう一度戦う場合、ゲストは②のIDか招待リンクから参加する。次の試合に新しい試合IDを割り当てる。
- ③ではホームへ退出できる。試合中に退出する場合は確認を表示し、降参として確定する。⑤から⑥への自動遷移は行わず、試合が中断した場合も、取得できた最後の盤面と中断理由を表示する。

### R3　二人に共通する対戦結果

試合の計算は1秒に60回。ステージの内部座標は、無印を幅390・高さ844の縦画面で表示したときの実測値で固定する。固定する値にはステージの幅と高さ、床と各部位の当たり判定の位置を含める。スマホの縦横切り替えや表示サイズ変更は画面の拡大縮小に反映する。

プレイヤーが送るのは操作と準備・降参・ルームに戻る意思。サーバーが位置、命中、部位破壊、残り時間、決着を確定する。操作を押した反応と自分の移動は端末で先に描いてよい。ダメージ・勝敗と、それに伴う効果音は確定結果から出す。同じ試合の同じ時点を照合すると、両画面の確定結果が一致すること。

### R4　切断と再接続

- 試合中は1秒ごとに接続を確認する。通信の切断、自動確認が3秒続けて途絶えたとき、またはアプリが裏に回った通知を受けたときに、サーバーで試合を一時停止し、押されたままの操作を解除する。
- 一時停止の猶予は、二人で共有する一試合あたり合計10秒。両者が戻ったら、同じ席と最新の確定状態から再開する。猶予が尽きた場合は勝敗をつけずに通信中断。操作による降参をサーバーが試合中に受け付けた場合は、相手の勝ちとする。開始前の退出は待合室に戻すか部屋を閉じ、決着済みの場合は確定結果を返す。
- 決着済みの結果を再接続時にも取得できるよう、結果の確定から5分間、試合IDごとに保管する。次戦は別の試合IDで開始する。⑤の盤面を復元するため、確定結果に最後の盤面を含めて保存する。サーバーが再起動した時点で未確定の試合は通信中断として扱う。確定済みの結果を優先する。
- 待合室は作成から10分以内に最初の試合を開始する。決着から5分以内にホストが戻れば、同じルームIDで待合を開き直す。戻った待合の参加期限は改めて10分。期限切れの部屋に戻ろうとしたときは⑥で案内する。満員、期限切れ、版違い、通信失敗、相手の退出を区別して案内し、ホームに戻れるようにする。

### R5　参加者・通信・表示

一部屋は二席。ルームIDは参加先の指定に使う。ホストの席だけが、決着した部屋を開き直せる。席の操作と復帰には、端末ごとに作る128ビット以上の秘密の鍵を使い、招待リンクやアプリのログに含めない。同じ席の再接続で古い接続を失効させ、試合ID・接続の世代・操作の連番で古い入力や二重処理を排除する。名前はプレーンテキストで表示する。

参加・接続・入力はサーバーで値と頻度を確認する。連続した入室要求は制限する。通信を受け付ける画面の許可元を環境別に設定し、席の鍵でも確認する。稼働確認に使うのは接続数、試合開始・終了件数、遅れ、切断理由など。電話番号やアカウント登録は参加条件に含めない。

### R7　ベストスコア・戦績・ソンカケpt

左右それぞれに無印の採点式を自分視点で適用し、対戦サーバーから届いた確定値を⑥に表示する。通信中断はスコア「—」と理由を表示する。詳細ランキングは三つのタブを持ち、初期表示はベストスコア。 [無印の採点処理](https://github.com/chameleonjp-lab/songen_wo_kakeyouka/blob/060b251a7016725bfd4e7886936eabf223b092d0/index.html#L2757-L2768)

| タブ | 行に表示するもの | 順位に使う値 |
| --- | --- | --- |
| ベストスコア | 順位、名前、最高スコア | 対象試合の最高スコア |
| 戦績 | 順位、名前、試合数、勝・負・分、勝率、戦績点 | 戦績点 |
| ソンカケpt | 順位、名前、ソンカケpt、通算スコア、戦績点 | ソンカケpt |

初版の算出式は以下。計算は四捨五入した表示値を使わずに行い、点数の小数部分を切り捨てる。

- 勝率 = 勝数 ÷ 試合数。試合数 = 勝数 + 負数 + 引き分け数。0試合は集計表の対象外。
- 戦績点 = ⌊10,000 × 勝数 ÷（試合数 + 10）⌋。同じ勝率が0%より高ければ、試合数が多いほど切り捨て前の点は上がる。少数の試合だけで勝率が高いときの上がり幅を抑える。
- 通算スコア = 対象のスコアの総和。負のスコアも加える。ソンカケpt = ⌊max（0, 通算スコア）× 戦績点 ÷ 10,000⌋。0勝または通算0点以下は0ptとする。
- 例として10試合を6勝3敗1分、通算8,000点なら、勝率60%、戦績点3,000、ソンカケptは2,400。各タブは値の高い順。同じ値は同順位にし、表示順だけを固定する。

名前を入力して決着した試合を、その席の記録に反映する。心臓での決着と時間切れは、スコアと戦績の両方に含める。降参は勝敗が確定するため戦績に含める。降参した試合のスコアは⑥で表示し、ランキングの最高・通算スコアは通常決着から集計する。通信中断も開始回数には含め、戦績は勝敗・引き分けが確定した試合から集計する。

同じブラウザで名前付き参加を続けた記録は、そのブラウザに保存したランキング用の資格で集計する。名前は表示用とし、同じ名前の別プレイヤーを別の行にする。対戦サーバーから確定した開始・結果だけを連携し、試合ID・席番号・イベント種別の組で再送を重複計上しない。表示名が空欄の参加は開始回数に加える。

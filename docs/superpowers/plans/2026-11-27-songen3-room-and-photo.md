# 尊厳を賭けようか3のルーム操作・記念撮影・共有

**目標**　iPhoneから4桁のIDで対戦相手を招待し、部屋に戻って続けて遊べるようにする。

## 初版

- 新規ルームに4桁の数字を発行し、コピーの横にXへの招待ボタンを表示する。投稿は「私と尊厳を賭けようよ！」、全角コロン付きのルームID、ハッシュタグ、招待URLを1行ずつ並べる。
- 待機室でオーナーだけが1P・2Pを入れ替え、相手を退出させられる。参加者は自分で退出でき、登録画面に戻ったら最後に入力したIDを復元する。欄内右端の×で入力と保存を同時に消す。
- 記念撮影では対戦終了時の姿を大きく中央に並べ、枠と重複する顔のカードを外す。「スコア結果へ」は表示開始2.5秒間無効にする。
- スコア結果には両者の「ルームに戻る」とX共有を用意する。ホームはルール説明、X共有、詳細ランキングの順とする。2枚目の添付を使った共有画像を、ゲームURLに設定する。

## 敵対的検証

同時に部屋を作った場合と、通信が途切れて作成を再試行する場合を確認する。席の入れ替え後に古い操作が届くと、新しい参加者や試合を変更するおそれがある。先に部屋へ戻った側の操作で相手の結果画面を消すと、相手がスコアを読めない。4桁のIDの先頭が0のときに数値へ変換すると招待に失敗する。画面回転と再読み込みでは、撮影の待ち時間や保存したIDにずれが出やすい。

## 修正版と受入条件

| 作業 | 実装と確認 |
| --- | --- |
| 招待 | IDは4桁の文字列で扱う。部屋側で使用中の番号を確保し、発行の再試行に同じ番号を使う。4桁の番号自体には操作権限を持たせず、席ごとの鍵と既存の回数制限を使う。従来の招待と公開中の旧画面は切り替え期間も利用できることを確認する。 |
| 待機室 | 席とオーナーの権限を分ける。待機中だけ席の変更・追い出しを許可し、入れ替え時は準備を解除する。操作要求は待機室の変更番号を照合する。退出・追い出し後は登録画面へ戻り、IDの×はブラウザーを開き直しても空欄のままとする。 |
| 決着と再戦 | 決着時の顔・部位・破損は保存済みの試合結果を使い、撮影用に左右の表示位置を固定する。撮影画面の表示から2.5秒後に結果ボタンを有効にする。先に戻った人だけを待機室へ移し、相手は自分で戻るまで結果画面に残る。 |
| 共有 | 招待文とURLの4桁を照合する。ホームとスコア結果でX共有を確認する。ホームのランキングは既存の詳細ページへ移動し、現在の実験場掲載とランキング公開の保留を維持する。画像はゲームURLと招待URLに共通の共有用メタ情報で取得できるようにする。 |

単体テストとiPhone相当のWebKitで、別々のセッションの参加、権限、回線復帰、終了から再戦までを検証する。比較対象は縦402×700と横700×402。
